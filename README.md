# AI Pathfinding Visualizer

Academic Mini Project

Course: Artificial Intelligence

Developed using React, Vite, TypeScript and Node.js to visualize and compare pathfinding algorithms including BFS, DFS, Dijkstra, UCS, Greedy Search and A*.

An interactive web application for visualizing and comparing popular pathfinding algorithms in real time.

## Features

✅ BFS (Breadth First Search)

✅ DFS (Depth First Search)

✅ Dijkstra's Algorithm

✅ Uniform Cost Search (UCS)

✅ Greedy Best First Search

✅ A* Search Algorithm

✅ Interactive Grid System

✅ Wall Placement

✅ Weighted Nodes

✅ Real-Time Animation

✅ Algorithm Comparison Mode

✅ Performance Metrics

## Algorithms Implemented

### Breadth First Search (BFS)
Guarantees shortest path in unweighted graphs.

### Depth First Search (DFS)
Explores deeply before backtracking.

### Dijkstra Algorithm
Finds shortest path in weighted graphs.

### Uniform Cost Search (UCS)
Expands the lowest-cost path first.

### Greedy Best First Search
Uses heuristic values to reach the goal faster.

### A* Search
Combines path cost and heuristic estimation for optimal pathfinding.
